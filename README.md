# Textbook Exchange App

An Android application built for CSC313 Assignment 2 using Object-Oriented Programming principles.  
It allows students to browse and list second-hand textbooks.

## Features

- Browse available textbooks
- Add new textbooks
- Navigate via a user-friendly interface

## Technologies

- Java
- Android Studio
- XML for UI layout
- Git & GitHub for version control
